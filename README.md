# Make a Form

## Overview

This is an experimental extension that provides a simplified interface for creating forms
in CiviCRM.

Note that this extension creates forms that are compatible with the Core Afform extension.

## Technology stack

- Frontend interface is built using SvelteKit, a Javascript framework.
- It inherits the theme configured by Riverlea extension.

This is an [extension for CiviCRM](https://docs.civicrm.org/sysadmin/en/latest/customize/extensions/), licensed under [AGPL-3.0](LICENSE.txt).

## Why does this extension exists?

- This extension started as an experiment during the Netherland Sprint in 2025. My goal was to create a simplified frontend interface using modern technology, for building forms in CiviCRM. In my opinion, this is kind of proof of concept for modernizing CiviCRM's frontend technology stack.

## Known Issues

- This extension only provides subset of the features available in the Core Afform extension.
- Use this extensions at your own risk
